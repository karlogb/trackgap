Questions

Shopify tracking gaps, explained.

Why do Shopify orders and GA4 transactions not match?

Common causes include declined analytics consent, blocked or broken purchase tags, duplicate events, processing delays, and values sent without shipping or tax. TrackGap matches orders by ID so these causes can be separated.

Does TrackGap modify my Shopify theme?

No. TrackGap uses official Shopify APIs and a Shopify web pixel extension. There is no theme code to install or maintain.

Can TrackGap recover missing GA4 conversions?

Yes, when the visitor granted the required consent and a valid GA4 client identifier is available. It never sends a conversion when consent is declined or cannot be demonstrated.

What customer data does TrackGap store?

No names, email addresses, postal addresses, phone numbers, or payment details. Reconciliation uses order IDs, values, timestamps, traffic sources, and the pseudonymous analytics identifiers it needs.
